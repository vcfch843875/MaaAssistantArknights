# 自動戦闘

作戦共有サイト [prts.plus](https://prts.plus) のご利用・作戦ファイル共有へようこそ。

::: warning
自動戦闘に関わる全ての機能は、少なくとも 60fps の安定したゲームフレームレートが必要です（自動戦闘・自動ローグライク等を含む）。
:::

## 作戦を使う（コピペ周回）

`編成可能ステージ` および `保全駐在` モードの自動戦闘に対応しています。

* この機能は、`行動開始` ボタンのある編成選択画面から起動してください。
  その後、MAA 左上の入力欄で `攻略ファイルパスをインポート` または `作戦サイトのミステリーコードを入力` すると作戦を取り込めます。
* `自動編成` は**現在の編成を全てクリア**し、作戦に必要なオペレーターで自動編成します。
  * 自動編成対象のオペレーターに設定している注目（お気に入り）を解除してください。
  * 任務に応じて `カスタムオペレーターの追加` や `信頼度低のオペレーター追加` を設定できます。
  * `戦友支援・サポート` を使う等の事情がある場合は `自動編成` をオフにし、手動で編成して開始してください。
  * 「逆理演算」ステージでは `自動編成` を必ずオフにし、スキルを手動選択したうえで、**演算開始** ボタンのある画面から自動戦闘を開始してください。
  * 「保全駐在」では `自動編成` は無効です。**初期**準備を手動で完了し、ステージ詳細に **配備開始** ボタンが出る画面になってから自動戦闘を開始してください。
* `周回回数` を設定できます（保全など）。ただし MAA は戦友のオペレーターを自動で借りません。戦友サポートが必要な場合は本機能を使用しないでください。
* `バトルリスト` 機能で同一エリア内のステージを自動連続戦闘できます。
  * バトルリスト下部の 3 つのボタンは左から順に `バッチインポート`・`ステージを追加`・`リストを空にする`。
    `ステージを追加` を右クリックで強襲作戦を追加、`リストを空にする` を右クリックで未チェックのステージのみ消去。
  * 作戦を取り込むと、バトルリスト下部にステージ名が表示されます。正しいことを確認してからそのステージを追加してください。リスト内ステージはドラッグで順序変更・チェックで実行可否を切替可能です。
  * この機能を有効にした場合は、**該当ステージのあるマップ画面**で自動戦闘を開始してください。理性不足／作戦失敗／★3未達成時には自動戦闘キューを停止します。
  * リスト内のステージが同一エリア（マップを左右スワイプだけで移動できる範囲）にあることを確認してください。
* **良質な作戦には必ず「いいね」を！ 作戦の評価向上と作者のモチベーションに繋がります。**

## 作戦エディタ

* [作戦エディタ](https://prts.plus/create) を使用してください。仕様は [自動戦闘プロトコル](../../protocol/copilot-schema.md) を参照。
* マップ座標の取得：
  * 作戦エディタでステージを入力すると、左下にドラッグ・拡大縮小可能な座標マップが自動表示され、クリックで現在のオペレーター位置を設定できます。
  * ステージを入力して JSON をエクスポート後にそのまま作戦開始すると、MAA ディレクトリの `debug\map` に座標情報を重ねたマップのスクリーンショットが生成されます。
  * [PRTS.Map](https://map.ark-nights.com/areas) の設定で `座標表示` を `MAA` に変更して利用してください。
* 演習モードに対応しています。
* 作戦説明には、署名（作者名）・参考の攻略動画リンク・補足などの記載を推奨します。
